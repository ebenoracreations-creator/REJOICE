# Rejoice Events & Floral Studio 🌸

> The Best of the Best Event Management Company in Kerala & No. 1 Event Planners in Kottayam.

Official website and custom interactive checklist suite for **Rejoice Events & Floral Studio**, Kanjirappally, Kottayam, Kerala.

## ✨ Features

- **Luxury Design & Animations**: Cormorant Garamond & DM Sans typography, smooth pinned stacking card deck animation, luxury glassmorphism cards, gold accents.
- **5 Custom Interactive Event Checklists**:
  - `wedding-checklist.html`: Complete 28-item wedding planning checklist.
  - `baptism-checklist.html`: 16-item baptism & holy communion celebration checklist.
  - `birthday-checklist.html`: Custom any-theme selector and 15-item party checklist.
  - `funeral-checklist.html`: Dignified, sacred memorial services checklist (pandal, hearse van, sound system, casket floral tributes).
  - `corporate-checklist.html`: 11-item executive conference & gala dinner checklist.
- **Direct WhatsApp Integration**:
  - Clients customize their checklist, enter contact details, and send formatted quotes directly to WhatsApp (`+91 99614 02646`).
- **Touch & Mobile Optimized**:
  - Entire package cards act as seamless touch/click gateways directly to each checklist.
  - 16px form inputs prevent auto-zoom on mobile browsers.
  - Sticky selection counter and one-click submission action bar.
- **SEO & Geo Optimization**:
  - Complete local business and event package Schema.org JSON-LD structured data.
  - Dynamic `sitemap.xml` and `robots.txt`.

## 🚀 Getting Started

Open `index.html` directly in any web browser, or serve locally:

```bash
# Using Node serve
npx serve -p 5500 .

# Or using Python
python -m http.server 5500
```

Visit: `http://localhost:5500`
